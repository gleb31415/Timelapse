# Лапс — таймлапс работы

Веб-приложение (PWA): снимает таймлапс работы за столом камерой телефона, считает рабочее время по дням и отмечает, когда ты уходишь из приложения в телефон.

- Кадр каждые 1–60 секунд, видео 24/30/60 к/с, 720p или 1080p.
- Перерывы не считаются работой. Если выйти из приложения, это засчитывается как отвлечение.
- Статистика по дням, цель на день, серия дней подряд, экспорт в CSV.
- Видео собирается прямо в телефоне в MP4 (H.264), с временем и отметками отвлечений.
- Кадры и статистика хранятся только на устройстве (IndexedDB), никуда не отправляются.

Установка: открыть сайт в Safari/Chrome → «На экран „Домой“» / «Установить приложение».
